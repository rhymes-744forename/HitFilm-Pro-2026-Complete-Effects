## Perguntas Frequentes (FAQ)

**1. Este pacote funciona com outras versões do HitFilm, como o Express ou versões anteriores a 2026?**
Este pacote foi especificamente desenvolvido e testado para a versão **HitFilm Pro 2026**. A compatibilidade com o HitFilm Express ou com versões anteriores do Pro (2025, 2024, etc.) não é garantida, pois a arquitetura dos efeitos e plugins pode sofrer alterações entre versões maiores. Recomendamos verificar a documentação oficial para conferir.

**2. After installing, I don't see the new effects/templates in HitFilm. What do I do?**
Geralmente, isso ocorre porque o HitFilm Pro não foi reinicado após a instalação. Feche completamente o software (verifique também o Gerenciador de Tarefas) e o reinicie. Se o problema persistir, verifique no HitFilm em `Opções > Arquivos` se os caminhos para "Efeitos" e "Modelos" incluem os diretórios onde o instalador colocou os novos arquivos. Você pode precisar adicioná-los manualmente.

**3. Isso inclui um "crack" ou chave de licença para o próprio HitFilm Pro?**
**Não.** Este pacote contém apenas recursos complementares (efeitos, plugins, templates) para serem utilizados com uma instalação legítima e licenciada do HitFilm Pro 2026. Ele não contém, modifica ou fornece任何形式 de bypass de licença, serial ou arquivo de ativação para o software principal. O uso destes recursos pressupõe que você possui direitos válidos de acesso ao HitFilm Pro.

**4. Os efeitos têm um impacto significativo no desempenho do meu computador?**
Alguns efeitos avançados, especialmente aqueles que envolvem 3D ou simulações de partículas complexas, podem ser exigentes para a CPU e GPU. O desempenho final dependerá das especificações do seu hardware. Para os melhores resultados com projetos pesados, recomenda-se um processador multi-core moderno, 16 GB de RAM ou mais e uma placa de vídeo dedicada com pelo menos 4 GB de VRAM.
